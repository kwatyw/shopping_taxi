Целью данной проектной работы являлась разработка прототипа приложения, с помощью которого покупатели смогут оптимизировать свое пребывание в торговых центрах, а именно: разработка приложения для быстрого поиска покупателем необходимых товаров среди большого ассортимента магазинов торговых центров. 

Данное приложение (при определении заранее заданных характеристик искомого товара администратором ТЦ) должно позволять рассылать запросы об искомом товаре продавцам магазинов, а при наличии товара и обратном отклике продавцов передавать информацию о магазинах, где покупатель может найти нужный ему товар, обратно администратору.
